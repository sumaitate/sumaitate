## Selected Work
### [NYISO Residual Learning for Solar Energy Generation](https://github.com/sumaitate/nyiso-solar-residual)
The goal of this project was to improve solar energy forecasts from NYISO by modeling the errors and correcting it. Instead of replacing the baseline system, I treated its mistakes as a signal and used machine learning to learn those patterns. The result was a measurable improvement in forecast accuracy, especially during peak generation periods, with about a 5.4% reduction in mean absolute error.
* Technologies: Python (pandas, NumPy), scikit-learn (Random Forest/Gradient Boosting), statsmodels (baseline time-series), Jupyter, Plotly
* Improved solar forecast accuracy by ~5.4% by learning when the system tends to over- or under-predict, leading to noticeably better predictions during high-production (sunny) periods.

### [My Music Revisits: Finding Tracks Worth Returning To](https://github.com/sumaitate/music-analytics)
This project uses 146 days of my personal listening history to examine behavioral patterns and uses those signals to build a recommendation system for finding tracks worth revisiting. I built a reproducible data pipeline, engineered features, used cosine-based nearest-neighbor search to identify similar tracks, and made am interactive dashboard for exploring listening patterns and recommendations.
* Technologies: Python (pandas, NumPy), scikit-learn, Plotly, Streamlit, Parquet
* Built an end-to-end analytics and recommendation pipeline covering 10,454 listening events across 2,962 tracks, with an interactive dashboard for exploring listening behavior and related-track recommendations.

### Currently Working On: [Machine Learning Classification of Variable Stars Using Gaia DR3 Light Curves](https://github.com/sumaitate/gaia-dr3-variable-star-classification)
I am conducting undergraduate research on whether classical machine-learning models can accurately classify common variable-star types using features extracted from Gaia DR3 photometric light curves. The project will examine time-series and astrophysical features such as period, amplitude, color, statistical distributions, Lomb-Scargle periodogram measurements, and Fourier features, while also investigating which features contribute most strongly to distinguishing variable-star classes.
* Technologies: Python, pandas, NumPy, scikit-learn, Gaia DR3, astronomical time-series analysis
* The research is being developed as a reproducible machine-learning pipeline covering Gaia data acquisition, light-curve preprocessing, feature extraction, model comparison, evaluation, and feature-importance analysis.
